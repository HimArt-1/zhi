# زهي | ZHI Coffee

جولة صور ومشهد تفاعلي ثلاثي الأبعاد لمقهى زهي، يتضمّن مجسّم البورش الزيتية 911 Carrera S (991.2). تعمل جولة الصور في المتصفحات التي لا يتوفر فيها WebGL.

## التشغيل

شغّل `npm run preview`، ثم افتح <http://localhost:4179/>. يستخدم Vercel الأمر `npm run build` لنشر محتويات `dist` على المسار الرئيسي. يحوّل المسار القديم `/zhi` إلى الصفحة الرئيسية.

لتشغيل اختبارات المتصفح، نفّذ `npm ci` و`npx playwright install chromium` ثم `npm test`.

## البيانات

يعرض قسم «وش قهوتك؟» أسماء وصور وأسعار المحاصيل المفردة من [قسم القهوة المختصة في متجر زهي](https://zhi-coffee.com/-/c1055379133)، مع رابط الشراء والسعر الحالي في المتجر. تبقى الطلبات التجريبية السابقة والحجوزات والولاء محفوظة في المتصفح.

متغيرات Supabase المطلوبة موضحة في `.env.example`. تُضبط في إعدادات Vercel، والمفتاح السري مخصص لخادم موثوق عند ربطه لاحقًا. الواجهة الحالية لا تتصل بقاعدة بيانات ريشيو.

## الأصول

صور الجولة مولّدة استنادًا إلى الصور المرجعية، ومجسّم السيارة مبني في `carrera.js` استنادًا إلى [مواصفات بورش](https://newsroom.porsche.com/en/products/porsche-911-carrera-new-2015-11366.html). تراخيص Three.js وخط Alexandria مرفقة.

## الافتتاحية

فيلم افتتاحي في الممر المضاء باستخدام مجسّم البورش المرفق باللون الزيتوني، بنسختين عريضة وطولية. يظهر تلقائيًا مرة لكل جلسة تصفّح ويمكن تخطّيه أو إعادة عرضه من تذييل الصفحة. يتخطّى المتصفح التشغيل التلقائي عند تفضيل تقليل الحركة.

لتصيير الافتتاحية من المصدر، ثبّت Chromium عبر Playwright وFFmpeg، ثم شغّل `node scripts/render-intro.mjs`. ينتج السكربت نسختي MP4 في `assets`.
